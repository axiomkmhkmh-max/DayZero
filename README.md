# 🌅 Day Zero — `@DayZeroGameBot`

بازی زندگی آزاد توی تلگرام: کار، کاسبی، خونه و خانواده، قمارخونه، و مبارزه‌ی بازیکن‌ها با هم.

## راه‌اندازی
1. در BotFather: `/setname` ← **Day Zero** ، `/setusername` ← **DayZeroGameBot**
2. **برای کار کردن دستورهای فارسی توی گروه:** `/setprivacy` ← **Disable** (وگرنه فقط دستورهای `/attack` و … دیده می‌شن)
3. متغیرها (`.env.example`): `BOT_TOKEN`, `MONGO_URI`, `REDIS_URL`, `BOT_USERNAME`
4. `pip install -r requirements.txt` و `python main.py`

دیتابیس پیش‌فرض `dayzero` است (دیتای ربات قدیمی `rust_tg` دست نمی‌خوره).

## دستورهای متنی (گروه و پیوی — ریپلای روی طرف یا @یوزر)
| دستور | کار |
|---|---|
| `حمله` / `حمله کلاشینکف` / `حمله کلاشینکف و شمشیر` | حمله‌ی ساده/تک‌اسلحه/ترکیبی؛ دفاع خودکاره |
| `دوز 50000` · `تاس 1m` | شرط‌بندی با بازیکن (برنده ۹۵٪ کل پول) |
| `ثبت ازدواج` | پیشنهاد ازدواج (طرف قبول/رد می‌کنه) |
| `درخواست طلاق` | درخواست طلاق (قبول همسر، یا یک‌طرفه بعد ۲۴ ساعت) |
| `بزن توش` | بچه‌دار شدن (۴۸ ساعت یک‌بار، ظرفیت = سطح خونه) |
| `حمله اجنه` · `دزد` · `طلسم عاشقی` · `طلسم طلاق` | آیتم‌های دارک وب |
| `جیبی` / `پول تو جیبی` | ۱٬۰۰۰ تا ۱۰٬۰۰۰ دلار شانسی (بیشتر ۲ تا ۴ هزار)، ساعتی یک بار |
| `کد هدیه کدت` | دریافت جایزه‌ی کد هدیه (فقط پیوی) |
| `جیب` / `منو` | موجودی / منوی بازی |

معادل‌های انگلیسی: `/attack /ttt /dice /marry /divorce /baby /pocket /gift /me /menu`

## منو توی گروه
`منو` یا `/menu` توی گروه، منوی کامل بازی (کار، کاسبی، خونه، بازار، بازی‌ها، مبارزه، اتحاد، رتبه‌بندی، جایزه، راهنما) رو همون‌جا باز می‌کنه.
- هر منو **فقط برای کسی که بازش کرده** کار می‌کنه (۲۴ ساعت)؛ بقیه پیام «این منوی تو نیست» می‌گیرن و باید خودشون «منو» بزنن.
- جاهایی که ربات اسم/یوزرنیم می‌خواد (ازدواج، حمله، جن، ساخت اتحاد…) توی گروه باید **روی پیام ربات ریپلای** کنی.
- دکمه‌های ازدواج/طلاق/دوئل مثل قبل فقط برای طرف مقابل کار می‌کنن.

## 🌆 چرخ تو شهر (زندگی روزمره)
دکمه‌ی «چرخ تو شهر» توی منو؛ هر ۴٫۵ دقیقه (`WALK_COOLDOWN_MIN`) بازیکن از بین ۳ جای شهر (بسته به ساعت تهران) یکی رو انتخاب می‌کنه. هر اتفاق دو راه داره و می‌تونه خوب یا بد تموم بشه؛ بعضی‌ها داستان چندمرحله‌ای دارن. پاداش‌ها (فقط روی سود، نه ضرر) با ضریب‌های زیر بالا می‌رن (سقف ×۳):
- 🔥 **استریک روزانه**: هر روز پشت‌سرهم چرخ بزنی +۳٪ (تا ۱۰ روز)
- ⚡ **کمبو**: چرخ بعدی رو تا ۱۲ دقیقه بعد بزنی کمبو ادامه داره، +۳٪ هر کمبو (تا ۱۰)
- 🌟 **ساعت طلایی**: ۱۰ دقیقه‌ی اول هر ساعت (وقت تهران) +۵۰٪
- 🎒 **کلکسیون یادگاری**: ۱۱ یادگاری؛ هر کدوم +۲٪ دائمی، ست کامل جایزه‌ی بزرگ داره
- 🤝 **آدم‌های شهر**: رفاقت (آشنا ← رفیق ← یار غار) پاداش اون آدم رو تا ۵۰٪ بیشتر می‌کنه
- ⚖️ **اعتبار (کارما)**: کارهای خوب/بد، شانس نتیجه‌ها رو عوض می‌کنه
- ✨ **اتفاق نادر** (۵ تا ۱۰٪ شانس، با استریک بیشتر): پاداش خیلی بزرگ + یادگاری نادر
- 📦 **صندوق روزانه**: با ۳، ۶ و ۱۰ چرخ تو یه روز جایزه می‌گیری
- 📔 **دفترچه‌ی شهر**: کشف اتفاق‌های جدید جایزه‌ی یک‌باره داره

همه‌ی عددها بالای `h_life.py` و اتفاق‌ها در `EVENTS` هستن.

## فرض‌هایی که خودم گذاشتم (در `config.py` عوضشون کن)
- قیمت 🍌 موز = ۵۰۰٬۰۰۰ و 🧪 معجون = ۱۰٬۰۰۰٬۰۰۰ (توی متن قیمت نبود). موز ۶ ساعت از تایمر بچه کم می‌کنه و ۷٪ درآمد؛ معجون تایمر رو صفر می‌کنه و ۵۰٪ درآمد (۲۴ ساعت).
- هر بچه‌ی سیر **+۲۵٪** درآمد کاسبی (جمعی، نه ضربی). هر کارگر درآمد پایه‌ی کسب‌وکار رو یک بار دیگه اضافه می‌کنه.
- ازدواج +۱۰٪ درآمد برای هر دو؛ اتحاد تا +۱۰٪.
- «شمشیر» رو به فروشگاه اضافه کردم (قدرت ۳۰۰، قیمت ۱۲۶٬۰۰۰) تا حمله‌ی «کلاشینکف + شمشیر» ممکن باشه.
- جن = ۲۴ ساعت قطع درآمد کاسبی و کار بچه‌ها؛ جنگیر ۳ بار جلوش رو می‌گیره.
- بازگشت پول بازی‌ها: اسلات ≈ ۹۴٪، گردونه ≈ ۹۱٪، شیر/خط و تاس ≈ ۹۵٪.
